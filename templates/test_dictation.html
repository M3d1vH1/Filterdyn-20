How Browser Dictation Works:

  1. Speech to Text: Browser converts your voice to plain text using Google's speech engine
  2. Pattern Matching: JavaScript searches the text for specific keywords like "Title:", "Description:", etc.
  3. Data Extraction: Extracts content after each keyword until it finds the next keyword or end of sentence
  4. Form Population: Automatically fills the appropriate form fields

Requirements: HTTPS, microphone permission, Chrome/Edge browser, internet connection

How Speech Parsing Works:

Step 1: You speak → Browser converts to text

Step 2: JavaScript finds keywords and extracts data

Try these examples:
Example 1:
"Title: Fix the water filter, Description: Replace the old filter with a new one, Priority: high, Assign to: John"
Example 2:
"Assign to: Sarah, Title: Update customer database, Priority: medium"
Example 3:
"Priority: urgent, Description: Server is down and needs immediate attention, Title: Emergency server repair"
Keywords that work:
  • Title: or Task: → Task name
  • Description: → Task details
  • Priority: → low, medium, high, or urgent
  • Assign to: or Assigned to: → Person's name
